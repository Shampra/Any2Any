Autoriser l’accès à Anytype

L’application Anytype vous demande de choisir les espaces autorisés, puis affiche un code à quatre chiffres.

Où saisir ce code ? Ici, dans cette petite fenêtre. Si Anytype passe au premier plan, revenez à cette fenêtre avec Alt+Tab (Windows). Vous pouvez laisser Anytype ouvert derrière.

Le code ne peut pas être lu automatiquement par l’API : cette validation protège l’accès à vos données. Anytype peut afficher le nom du processus « Python » lorsque l’outil est lancé comme script.

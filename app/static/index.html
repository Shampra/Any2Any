AVANT D’IMPORTER

Limites connues de la migration

Certaines fonctionnalités d’Anytype ne peuvent pas être reprises à l’identique dans Anytwo. Cette liste n’est pas exhaustive. Les différences de fonctionnement entre les deux applications peuvent également empêcher l’import de fonctionnalités pourtant présentes dans les deux.

Éléments signalés à ce stade

  • Couleur de background
  • Types
  • Templates
  • Propriétés globales
  • Propriétés locales
  • Table des matières
  • Bookmarks
  • Vues / Queries
  • Certaines vues de collection
  • Filtres avancés
  • Collection et vues intégrées dans les pages
  • Propriétés intégrées à la page
  • Discussions

Le contenu de ces éléments pourra parfois être adapté ou conservé partiellement, mais pas nécessairement leur comportement ou leur présentation. La conversion réelle peut entraîner des adaptations ; consultez le bilan de chaque import.

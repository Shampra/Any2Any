### English

Any2Any 0.11.0 makes Anytype imports cleaner and the interface fully bilingual.

- Anytype inline `@` mentions become real object links, in text, tables, columns and the page description.
- Internal Anytype bookkeeping (`Source object`, `template_name_prefill_type`, …) is no longer imported as Anytwo columns. Matching is by identifier, never by label or prefix: custom properties such as `template_notes` are preserved, and untranslatable template settings are reported.
- Native Anytwo templates are imported with their content, properties and an unambiguous collection default; top-level tables of contents become native dynamic blocks on compatible versions.
- Empty or relative property values no longer fail a page, and relation columns always receive valid `any://` arrays.
- Relations to objects that were not imported no longer add a duplicate `X (Anytype)` text column.
- Preserve native advanced blocks on the current Anytwo client, including toggles, columns, inline views, embedded properties, synced blocks, captions, media and dynamic tables of contents. Preserve code examples and empty paragraphs without version-based marker stripping.
- Warnings and labels written inside imported pages follow the interface language (French, English, German).
- The whole interface is translated into English and German, including import reports, errors and progress; the import window fits the screen.
- Every technical guide now exists in French and English.
- A macOS double-click launcher (`Any2Any.command`) joins the Windows `demarrer.bat` and the standalone `Any2Any.exe`.

Download the standalone Windows x64 ZIP or the source ZIP. Both have SHA-256 checksums. This is an experimental prerelease.

### Français

Any2Any 0.11.0 rend les imports Anytype plus propres et l’interface entièrement bilingue.

- Les mentions `@` Anytype deviennent de vrais liens d’objet, dans le texte, les tableaux, les colonnes et la description.
- La comptabilité interne d’Anytype (`Source object`, `template_name_prefill_type`, …) n’est plus importée comme colonnes Anytwo. La reconnaissance se fait par identifiant, jamais par libellé ni par préfixe : les propriétés personnalisées telles que `template_notes` sont conservées et les réglages de template non transposables sont signalés.
- Les templates natifs Anytwo sont importés avec leur contenu, leurs propriétés et un défaut de collection déterminable ; les sommaires de premier niveau deviennent des blocs dynamiques natifs sur les versions compatibles.
- Une valeur de propriété vide ou relative ne fait plus échouer une page, et les colonnes de relation reçoivent toujours des tableaux `any://` valides.
- Les relations vers des objets non importés n’ajoutent plus de colonne texte en double « X (Anytype) ».
- Conserver les blocs avancés natifs sur le client Anytwo actuel : toggles, colonnes, vues en ligne, propriétés intégrées, blocs synchronisés, légendes, médias et sommaires dynamiques. Préserver les exemples de code et paragraphes vides sans retrait de marqueurs selon la version.
- Les avertissements et libellés écrits dans les pages importées suivent la langue de l’interface (français, anglais, allemand).
- Toute l’interface est traduite en anglais et en allemand, y compris les bilans, erreurs et progressions ; la fenêtre d’import tient dans l’écran.
- Chaque guide technique existe désormais en français et en anglais.
- Un lanceur macOS à double-clic (`Any2Any.command`) rejoint `demarrer.bat` et l’exécutable autonome `Any2Any.exe`.

Téléchargez le ZIP Windows x64 autonome ou l’archive source. Les deux archives sont accompagnées d’une empreinte SHA-256. Cette version est une préversion expérimentale.

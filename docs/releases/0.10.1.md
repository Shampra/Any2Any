## English

- **Standalone Windows x64 application:** extract `Any2Any-Windows-0.10.1.zip` and run `Any2Any.exe` at the top level. Python is bundled under `_internal`; no separate Python installation is required. Documentation and licenses are under `documentation`.
- **Clean source layout:** `demarrer.bat` and `demo.bat` remain at the top level. Runtime code and UI resources are in `app/`; tests, builders, examples and development utilities are in `dev/`.
- The source archive is still available for Python 3.10+ users and other operating systems: run `demarrer.bat` or `python app/server.py`.
- Existing remembered settings remain in the same user profile. Moving or replacing the application folder does not reset them. Anytype and Notion import behavior is unchanged.
- Both source adapters are regression-tested; the Windows archive is extracted and its executable is started in demo mode before publication. ZIP files have separate SHA-256 checksums and internal manifests.
- Experimental prerelease. The import limitations described in the application remain applicable. No live migration is performed by the packaging checks.

## Français

- **Application Windows x64 autonome :** décompressez `Any2Any-Windows-0.10.1.zip`, puis lancez `Any2Any.exe` à la racine. Python est inclus dans `_internal` : aucune installation séparée n’est nécessaire. La documentation et les licences se trouvent dans `documentation`.
- **Arborescence source rangée :** `demarrer.bat` et `demo.bat` restent à la racine. Le code et les ressources de l’interface sont dans `app/` ; tests, outils de construction, exemples et utilitaires de développement sont regroupés dans `dev/`.
- L’archive source reste disponible avec Python 3.10+ et pour les autres systèmes : `demarrer.bat` ou `python app/server.py`.
- Les réglages mémorisés restent dans le même profil utilisateur. Déplacer ou remplacer le dossier de l’application ne les réinitialise pas. Le fonctionnement des imports Anytype et Notion est inchangé.
- Régressions des deux sources contrôlées ; l’archive Windows est extraite et son exécutable démarré en démo avant publication. Chaque ZIP a son SHA-256 et un manifeste interne.
- Préversion expérimentale. Les limites d’import affichées dans l’outil restent applicables. Les contrôles de packaging ne déclenchent aucune migration réelle.
